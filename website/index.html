FAQ

Questions

Is BoltPDF really free?
Yes — completely free, with no sign-up, trial or subscription. It's open-source under the AGPL-3.0 licence, so you can use, study, share and modify it.
Can I edit PDFs, or just read them?
Both. BoltPDF is a fast reader and also a full editor (currently in beta): edit text and images, add shapes/highlights/notes, redact, stamp, number pages, and undo/redo any change.
How does the OCR work?
It uses the OCR engine built into Windows 10 and 11 to make scanned pages selectable and searchable. No extra software, API keys or internet connection is needed for OCR.
Does it track me or send my files anywhere?
No. There's no telemetry, analytics or account, and your documents never leave your computer. The only network use is an optional check to GitHub for a newer version.
Does it work on Mac or Linux?
Windows 10 and 11 (64-bit) only — the OCR relies on Windows' built-in recognition engine.
Is it safe to install?
It's fully open-source, so you (or anyone) can inspect the code and build it yourself. It ships as a small Windows installer that adds a Start Menu entry and an optional default-PDF-app association.
