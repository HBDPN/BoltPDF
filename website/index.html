FAQ

Questions

Is BoltPDF really free?
Yes — completely free, with no sign-up, trial or subscription. It's open-source under the AGPL-3.0 licence, so you can use, study, share and modify it.
Can I edit PDFs, or just read them?
Both. BoltPDF is a fast reader and also a full editor (currently in beta): edit text and images, add shapes/highlights/notes, redact, stamp, number pages, and undo/redo any change.
How does the OCR work?
It uses the OCR engine built into Windows 10 and 11 to make scanned pages selectable and searchable. No extra software, API keys or internet connection is needed for OCR.
Does it track me or send my files anywhere?
No. There's no telemetry, analytics or account, and your documents never leave your computer. The only network use is an optional check to GitHub for a newer version.
Does it work on Mac or Linux?
Windows 10 and 11 (64-bit) only — the OCR relies on Windows' built-in recognition engine.
Is it safe to install?
It's fully open-source, so you (or anyone) can inspect the code and build it yourself. It ships as a small Windows installer that adds a Start Menu entry and an optional default-PDF-app association.
Does BoltPDF add watermarks?
No. BoltPDF never watermarks your documents and never charges to remove anything — exported and edited PDFs are clean.
Does it work offline?
Yes — every feature, including OCR, works completely offline. The only time it uses the internet is an optional check to GitHub for a newer version.
Can it edit or OCR scanned PDFs?
Yes. Run the built-in OCR to make a scanned PDF's text selectable and searchable, then annotate, highlight or redact it like any other document.
Can I set BoltPDF as my default PDF reader?
Yes. The installer can register BoltPDF as a Windows PDF handler and add a Start Menu entry, so PDFs open in BoltPDF automatically if you choose.
Is there a free PDF editor for Windows with no subscription?
Yes — that's BoltPDF. Reading and the full editing/annotation toolset are free with no subscription, account or trial.

Guides

How to do common PDF tasks — free

What is BoltPDF?

BoltPDF is a free, open-source PDF reader and editor for Windows 10 and 11. It renders pages with Google's PDFium engine (the same one in Chrome), so even large or complex PDFs open instantly. Unlike many "free" tools, BoltPDF never adds watermarks, never asks you to sign up, and processes every document entirely on your computer.

How to OCR a scanned PDF for free

Scanned PDFs are images, so the text can't be selected or searched until you run OCR. In BoltPDF:

  1. Open the scanned PDF.
  2. Click the OCR (“Detect Text”) button on the toolbar.
  3. Wait a moment — BoltPDF overlays selectable, searchable text using Windows' built-in OCR. No internet, API keys or extra software needed.

How to redact a PDF

Need to hide sensitive information before sharing?

  1. Turn on Edit mode and choose the Whiteout / Redact tool.
  2. Drag a box over the text or image you want gone.
  3. Use Save As — the covered content is removed from the exported PDF, not just hidden.

How to edit text in a PDF

In Edit mode (beta), click a block of existing text and type your changes — BoltPDF matches the original font style so edits blend in — then Save As. You can also add new text boxes, images, shapes, highlights, stamps and page numbers.

How to read a PDF as a two-page spread

Open the Layout menu and pick Two-page spread to view facing pages side by side, like a book — or switch to continuous scroll or single-page at any time. Add reading tints (night, sepia, warm, dim) for comfortable long reads.

Who uses BoltPDF?

Students reading textbooks and papers, professionals reviewing and marking up contracts, accountants checking statements, researchers annotating PDFs, and anyone who wants a fast, private, no-cost alternative to bloated PDF software on Windows.
